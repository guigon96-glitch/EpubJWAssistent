# Leitor de Discursos — app Android (tablet)

Código-fonte do app do tablet que mostra os EPUBs do **Criador de EPUB** salvos no Google Drive.

- **Baixar o app:** veja as versões `android-vX.Y` em [Releases](https://github.com/guigon96-glitch/EpubJWAssistent/releases) (ou use o botão *Atualizar app* dentro do app).
- **Guia de uso e instalação:** [GUIA-ANDROID.txt](GUIA-ANDROID.txt)
- **Para continuar o desenvolvimento:** [CLAUDE.md](CLAUDE.md) (mesmo conteúdo de `CONTEXTO.md`).

A chave de assinatura (`.jks`) e as senhas **não** ficam aqui: o dono do projeto as guarda à parte.
