# Criador de EPUB

Aplicativo para Windows para escrever discursos e livros e salvá-los em **EPUB**, com:

- Editor parecido com o Word (formatação, imagens redimensionáveis, tabelas, títulos e sumário)
- **Anotações**: selecione um texto → botão direito → *Adicionar anotação*
- **Textos bíblicos automáticos** (Tradução do Novo Mundo, buscados no jw.org)
- **Base para comparação**: abra o esboço (.docx, PDF, EPUB) ao lado do texto
- **Google Drive**: entre com sua conta Google e salve/abra seus EPUBs de qualquer computador
- **Atualização automática**

## Baixar

Vá em **[Releases](../../releases/latest)** e baixe `Instalar-Criador-de-EPUB-x.y.z.exe`.

Na primeira instalação o Windows pode mostrar *"O Windows protegeu o computador"* (o app não tem
assinatura digital paga): clique em **Mais informações → Executar assim mesmo**.
Depois disso, as novas versões são instaladas pelo próprio app.
